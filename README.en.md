**Theoriturgy** is the disciplined methodology for producing theories. A theory is not an inspired artifact but a reproducible production flow: topic selection → prior-art search → registration → anchoring → empirical validation → dissemination → evolution. Every theory must be **Registered** (named identity), **Verified** (empirical support plus recorded counter-evidence), and **Gated** (prior-art search and validation before release).

## When to use

Use when producing or validating a theory, doctrine, or methodology claim within the LGD system; also as the production protocol for new theory assets.

## Definition

Theoriturgy treats theory as a reproducible engineering flow rather than inspiration. It is distinct from formal-verification "theory engineering": it targets the social-technical production of governance, standards, and skills.

## Verification

Multi-round, multi-dimensional prior-art search completed; zero conflicts across all dimensions (R1+R2, 2026-10-14).

## Examples

Production-flow checklist:

```markdown
- [ ] Topic: one-sentence theory claim
- [ ] Prior-art: multi-dimension search (academic/code/package/domain/variant/phrase)
- [ ] Registered: unique name + version
- [ ] Anchored: core proposition stated in one sentence
- [ ] Verified: supporting evidence AND recorded counter-evidence
- [ ] Disseminated: citable form (DOI / link)
- [ ] Evolvable: versioned revision path
```
